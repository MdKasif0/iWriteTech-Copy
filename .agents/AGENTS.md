# Project Rules

- **Git Behavior**: Do NOT automatically push changes to GitHub. Commit changes locally if necessary, but wait for explicit user instruction before running `git push`.

## Typography (Design Anchor)
- **Headlines and Logo:** Literata (Serif) via next/font. Applied globally to all H1/H2 tags site-wide.
- **Body Text and UI:** Geist Sans
- **Data/Prices:** Geist Mono
